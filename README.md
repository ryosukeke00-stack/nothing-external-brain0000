# EXTERNAL BRAIN — Nothing Phone向け最小版

## 実装済み
- 今日のタスク追加・完了・削除
- アイデア保存・分類・タスク化・削除
- ChatGPT向けプロンプト生成、コピー、ChatGPTを開く
- 売上・経費の記録、今月の集計
- 25分集中タイマー
- JSONバックアップの書き出し・読み込み
- ブラウザのlocalStorageへの保存
- PWA用manifestと192/512pxアイコン
- HTTPS環境でのService Worker登録と基本的なオフラインキャッシュ

## 未実装・制約
- AI APIによる自動回答・自動送信・会話履歴取り込み
- クラウド同期、複数端末同期、ログイン
- AndroidのYouTube/X利用時間の読み取りや制御（OS設定で行う）
- 税務用帳簿・領収書管理
- オフラインキャッシュは基本実装済み。ただし初回アクセスには通信が必要で、ブラウザ仕様により挙動が異なる
- データはブラウザのlocalStorage。ブラウザデータ消去等で失われる可能性があるため定期的にJSONバックアップする。

## ローカルで試す
index.htmlをブラウザで開くと基本機能を試せます。ただし、ブラウザによってはファイルURLで一部機能が制限されます。
ホーム画面への追加は、HTTPSで配信されたURLをChromeで開く方法を推奨します。

## Nothing Phoneへの導入（推奨）
1. PCでこのフォルダを解凍。
2. index.html と manifest.webmanifest を同じフォルダに置いたまま、HTTPS対応の静的ホスティングへ配置（例：GitHub Pages。公開範囲とプライバシーを確認）。
3. 発行されたHTTPS URLをNothing PhoneのChromeで開く。
4. Chromeの「︙」→「ホーム画面に追加」または「アプリをインストール」が表示された場合はそれを選ぶ（表示名はブラウザにより異なる）。
5. ホーム画面のアイコンから起動し、テスト用タスクを追加して保存を確認。
6. 設定・保存タブからJSONバックアップを定期的に書き出す。

## 注意
これは個人用のローカル記録アプリです。公開URLで運用する場合、入力した内容はその端末のブラウザ内に保存されますが、ホスティング先やアクセスログ等の公開設定には注意してください。秘密情報や児童の個人情報を入力しないでください。
